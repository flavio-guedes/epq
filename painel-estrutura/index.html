Fluxo de uso

COMO USAR

01 - Apoio

Referências visuais, textuais e inspirações para o job. Uso opcional, mas recomendado.

  • Referências de estilo
  • Imagens de apoio
  • Textos ou materiais existentes

02 - Briefing

Documento obrigatório antes de criar. Ele define objetivo, público, mensagem, CTA e direção de arte.

  • Modelo oficial EPQ
  • Sem este arquivo, não criar
  • Base para aprovação

03 - Arquivo Finalizado

Versão final publicável na raiz. Versões antigas vão para OLD.

  • Arte final na raiz
  • OLD guarda versões
  • Rastreabilidade simples

Regras rápidas

GOVERNANÇA
  • Toda peça nasce de briefing oficial preenchido e aprovado.
  • O briefing é o documento de governança da peça.
  • Cada job tem estrutura padronizada para manter consistência.
  • OLD guarda versões antigas; a raiz guarda a versão final.
  • Referências ajudam, mas não substituem o briefing.
  • Se a peça sair do sistema, pare, registre o desvio e proponha alternativa.
